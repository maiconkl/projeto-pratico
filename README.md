## Versionamento Semântico
O Versionamento Semântico utiliza o formato **MAJOR.MINOR.PATCH** para atribuir versões aos softwares:

* **MAJOR (Maior):** Incrementado quando há mudanças incompatíveis (quebra de compatibilidade).
* **MINOR (Menor):** Incrementado quando novas funcionalidades são adicionadas, mantendo a compatibilidade.
* **PATCH (Correção):** Incrementado para correções de falhas (bugs) sem quebrar funcionalidades existentes.
